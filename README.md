# ثَمَر | Thamar Financial Hub

منصة مالية تجريبية تساعد المستخدم على فهم وضعه المالي الشخصي وربطه بالمؤشرات الاقتصادية والسوقية، بهدف تقديم تقييم استرشادي لمدى ملاءمة عدد من الخيارات الاستثمارية.

## فكرة المشروع

تعتمد ثَمَر على دمج المؤشرات المالية الداخلية للمستخدم مثل:
- الدخل الشهري
- المصروفات
- المدخرات
- صندوق الطوارئ
- معدل الادخار
- مؤشر الاستدامة المالية

مع مؤشرات السوق والاقتصاد مثل:
- الذهب
- الأسهم
- البيتكوين
- النفط
- التضخم
- أسعار الفائدة

ثم تعرض درجة ملاءمة، مستوى مخاطر، وعائدًا تقديريًا لكل خيار استثماري.

## أهم المميزات

- دعم العربية والإنجليزية
- لوحة "محفظتك المستقبلية"
- مؤشر الاستدامة المالية
- رسوم بيانية للمؤشرات الشخصية
- متابعة اتجاهات السوق
- مقارنة فرص الاستثمار
- توصيات استرشادية مخصصة
- مساعد مالي ذكي
- صفحة سياسة الخصوصية

## الخصوصية والأمان

يستخدم المشروع في نسخته الحالية بيانات تجريبية، ولا يطلب بيانات حساسة مثل:
- رقم الهوية
- الحساب البنكي
- أرقام البطاقات
- كلمات المرور البنكية

وعند استخدام APIs مستقبلًا، يتم حفظ المفاتيح داخل Secrets / Environment Variables، ولا يتم تضمينها داخل الكود العام أو رفع ملفات مثل `.env` إلى GitHub.

## تنبيه استثماري

جميع الأرقام والمؤشرات والعوائد التقديرية في النسخة الحالية لأغراض تجريبية واسترشادية فقط، ولا تمثل ضمانًا للربح أو توصية استثمارية مؤكدة.
