## التقنيات المستخدمة

تم تطوير المشروع باستخدام مجموعة من الأدوات والتقنيات، من أبرزها:

- Lovable لتطوير وتعديل واجهة المشروع.
- GitHub لإدارة الكود وحفظ التحديثات.
- Vercel لنشر الموقع وتشغيل النسخة النهائية.
- React / TypeScript لبناء واجهة المستخدم.
- TanStack Router لإدارة التنقل بين صفحات المشروع.
- Tailwind CSS لتنسيق وتصميم الواجهة.

## البرنامج التدريبي

تم تنفيذ مشروع **THAMAR | ثمر** ضمن أحد البرامج التدريبية المقدمة من **أكاديمية سدايا**، بهدف تطبيق مهارات تطوير المنتجات الرقمية، بناء واجهات المستخدم، وإدارة ونشر المشاريع التقنية.
